# Model Card: Model D – Yield Prediction

- **Objective**: Quantile yield prediction (P10, P50, P90) in tonnes / ha.
- **Inputs**: Soil organic carbon, NDVI, seasonal rainfall, historical crop baseline quantiles.
- **Outputs**: Expected yield quantiles per crop ($P_{10}, P_{50}, P_{90}$).
- **Fallback**: Crop registry baseline historical quantiles.
